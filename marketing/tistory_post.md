# [퀀트/오픈소스] 나스닥 & NYSE 4,500개 전 종목을 0.35초 만에 스캔하는 초단타 AI 트레이딩 터미널 (FastAPI + TradingView CDP + Claude Code)

안녕하세요. 퀀트 개발 및 시스템 트레이딩 아키텍처를 연구하는 개발자입니다.

미국 주식 시장은 일일 거래 종목만 5,000개에 달하며, 고주파 알고리즘(HFT)과 기관 매수세가 초단위로 호가창을 집어삼키는 전쟁터입니다. 개인 투자자가 HTS나 웹 스크리너를 수동으로 새로고침하면서 모멘텀 종목을 잡으려 하는 것은 필패에 가깝습니다.

이번 포스팅에서는 **미국 나스닥(NASDAQ) 및 뉴욕증권거래소(NYSE) 상장 전 종목의 상대 거래량(RVOL)과 가격 임팩트를 실시간 분석하고, 초단위 상승 파동을 노릴 수 있는 상위 3개(TOP 3) 종목을 자동 추출하는 일체형 AI 트레이딩 시스템(ALPHA-3)**의 아키텍처와 구현 방법을 정리합니다.

전체 소스코드는 GitHub에 MIT 라이선스로 공개되어 있습니다.

## 2. 모멘텀 스캘핑 매트릭스 알고리즘 (Alpha-3 Formula)

스캘핑의 성공률을 극대화하려면 '단순 가격 상승'이 아니라 **'호가창을 밀어올리는 순수 거래량 가속도'**를 측정해야 합니다.

시스템은 다음 4가지 정량 지표를 기반으로 `0.0 ~ 99.9`점의 모멘텀 스코어를 연산합니다:

### ① 상대 거래량(RVOL) 폭증 계수 (최대 35점)
$$\text{RVOL} = \frac{\text{Volume}}{\text{AvgVolume}_{10d} \times \text{SessionProgress}}$$
- 10일 평균 거래량 대비 **10배 이상** 유입 시: 35점 만점
- 5배 이상 유입 시: 28점

### ② VWAP(거래량 가중 평균가) 지배력 & 시가 대비 확장성 (최대 30점)
- 주가가 당일 VWAP 위에 위치하고, 괴리율이 $0.2\% \le \Delta \le 4.0\%$ 구간에 있을 때 20점 가산 (최적의 눌림목 돌파 스윗스팟)
- 주가가 VWAP 하단에 위치할 경우 -10점 감점 (가짜 돌파 트랩 방지)
- 장 시작가(Open) 대비 $+5\%$ 이상 지속 확장 시 10점 추가 가산

### ③ 당일 고가(High) 구조적 돌파도 (최대 20점)
- 현재가가 당일 고가 대비 상위 $5\%$ 이내에 밀집되어 있을 때 20점 만점 부여

### ④ 단기 기술적 지표 합치 (최대 15점)
- 초단기 7봉 RSI(`RSI7`)가 $55 \sim 82$의 강력한 모멘텀 가속 밴드에 있을 때 10점 가산

## 3. Chrome DevTools Protocol(CDP)을 이용한 트레이딩뷰 데스크톱 연동

트레이딩뷰는 공식적으로 외부 로컬 애플리케이션과의 차트 조작 API를 공개하지 않지만, **TradingView Desktop 앱**은 Electron 기반으로 빌드되어 있으므로 **CDP(포트 9222)**를 열어 원격 제어가 가능합니다.

### 쉘 스크립트를 통한 디버깅 포트 기동 (`launch_tradingview.sh`)
```bash
/Applications/TradingView.app/Contents/MacOS/TradingView --remote-debugging-port=9222 &
```

사용자가 터미널 UI에서 **`⚡ SYNC DESKTOP`** 버튼을 클릭하면, FastAPI 백엔드가 Node.js 기반 `tradingview-mcp` CLI(`tv symbol <TICKER>`)를 트리거하여 데스크톱 앱의 활성 차트와 주기를 1분봉(`1m`)으로 즉시 전환합니다.

## 4. 파인스크립트(Pine Script v5) 검증 전략

시스템 내 [`pine_strategies/`](https://github.com/henrynkoh/AI_Trading/tree/main/pine_strategies) 디렉터리에는 트레이딩뷰 컴파일러 검증(0 에러, 0 경고)을 마친 고성능 스캘핑 전략이 탑재되어 있습니다:

- **VWAP Trend Pullback Strategy:** 9/21/200 EMA 정배열 상태에서 VWAP 터치 후 반등하는 파동을 캐치하며, 손절 라인을 VWAP 하단 $1.2 \times \text{ATR}$로 고정.
- **Premarket Breakout Strategy:** 프리마켓(04:00~09:30 ET)의 최고점과 최저점을 세션 변수로 추적하여 정규장 개장 즉시 돌파 매수를 집행.

## 5. 실행 및 로컬 환경 구축 방법

```bash
# 1. 레포지토리 클론
git clone https://github.com/henrynkoh/AI_Trading.git
cd AI_Trading

# 2. 의존성 패키지 설치
pip install -r requirements.txt

# 3. 트레이딩뷰 데스크톱 CDP 모드 실행
./launch_tradingview.sh

# 4. 통합 서버 및 웹 터미널 구동
python3 server.py
```

브라우저에서 `http://localhost:5001`에 접속하면, 4,500개 종목의 실시간 스캐닝 결과와 함께 TOP 3 급등 스캘핑 카드가 렌더링됩니다.
